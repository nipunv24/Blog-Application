Blog-Fire: A Basic Express.js App
Overview
Blog-Fire is a straightforward Express.js application showcasing fundamental web development skills with Node.js. It includes basic CRUD (Create, Read, Update, Delete) operations for blog posts, illustrating how to manage HTTP requests and server-side rendering.

Technology Stack
Express.js 🌐: Web framework for server and request handling.
EJS 🧩: Templating engine for HTML rendering.
Body-Parser 📦: Middleware for parsing request bodies.
Method-Override 🔄: Middleware for supporting PUT and DELETE methods.
Node.js 🚀: JavaScript runtime for server-side code.
Skillset Demonstrated
Routing 🛤️: Managing routes for various HTTP requests.
CRUD Operations 📝: Implementing basic Create, Read, Update, and Delete functionalities.
Server-Side Rendering 🖥️: Using EJS for dynamic HTML content.
Middleware Usage ⚙️: Handling form data and HTTP methods.
