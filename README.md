## Blog-Fire: A Basic Express.js App

### Overview

**Blog-Fire** is a simple Express.js application that demonstrates fundamental web development concepts and server-side programming with Node.js. It includes basic CRUD (Create, Read, Update, Delete) operations for blog posts.

### Technology Stack
- **Express.js** 🌐: Web framework for server and request handling.
- **EJS** 🧩: Templating engine for rendering HTML views.
- **Body-Parser** 📦: Middleware for parsing incoming request bodies.
- **Method-Override** 🔄: Middleware for supporting PUT and DELETE methods.
- **Node.js** 🚀: JavaScript runtime for server-side code.

### What I Tried to Learn
- **Routing** 🛤️: Managing routes for handling various HTTP requests.
- **CRUD Operations** 📝: Implementing Create, Read, Update, and Delete functionalities.
- **Server-Side Rendering** 🖥️: Using EJS for dynamic HTML content.
- **Middleware Usage** ⚙️: Handling form data and HTTP methods with middleware.
